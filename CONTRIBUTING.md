# Contributing

Thanks for your interest in contributing! We welcome bug reports, feature
requests, and pull requests.

> All third-party contributors acknowledge that any contributions they provide
> will be made under the same open-source license that the open-source project
> is provided under.

## Reporting issues

Open an issue describing the problem or request. For bugs, include steps to
reproduce, what you expected, and what actually happened.

## Pull requests

- Keep pull requests small and focused on a single change.
- For changes that affect the API or behavior, open an issue to discuss it
  first.
- Make sure the project still builds and runs (see the setup steps in the
  [README](./README.md)).

## Code of Conduct

This project is governed by our [Code of Conduct](./CODE_OF_CONDUCT.md). By
participating, you are expected to uphold it.
